# 纯 Web 实施路线图

用户于 2026-10-25 要求做 Web 并开始实施。此文覆盖先前双端方案；本项目后续仅保留 Web 的产品、构建和验收任务。

首轮交付目标为 **0.1.0 可玩原型**：出生、成长、修行或谋生、抉择、终章、前世录和存档闭环，配套原创画面与真实文件导出。后续按下列阶段继续扩展。

| 阶段 | 交付内容 | 当前状态与下一步 |
|---|---|---|
| W0 世界与来源 | 规则、原创边界、目录与数据契约 | 首版基线已实现并落档；扩展内容持续审校 |
| W1 人生与持久化 | 月时钟、RNG、实体、队列、条件、版本与安全存档 | 核心已实现；新版本继续维护迁移契约 |
| W2 完整人生 | 出生、成长、选择、终章、年表与前世 | 可玩闭环已实现；愿望回顾待补 |
| W3 修行与生计 | 突破、失败、职业、资源、物品与家缘 | 基础已实现；优先补丹方、炼器、符阵、产业与更长的关系故事 |
| W4 活世界 | 地域、势力、同代人物、迁移与时代事件 | 基础已实现；继续补派系制度、外交、秘境与同代曲线对照 |
| W5 故事与视觉扩量 | 多地域故事、活动表现、完整洞府编辑、移动布局与声音 | 首版场景与 22 类故事已接入；需要更长故事链和更多人物活动 |
| W6 回顾与转移 | 分享、传记、详细回顾、纪念展示与跨设备存档 | PNG/HTML/CSV/JSON、打印路径和本地转移已实现；视频、相册与云备份待实施 |
| W7 公共能力 | 公共传记、社区与实际统计，按需商业化 | 未实施；先确定新产品的后端、账号、数据范围和发布方案 |
| W8 Web 首发 | 内容验收、平台回归、版本锁、静态部署与回退 | 本地引擎、Chrome／手机视口与实际静态构建验收通过；公开发布和跨浏览器／真机验收尚待完成 |

原功能域逐项对照：

| 功能域 | 0.1.0 已有 | 待补齐 |
|---|---|---|
| F01 出生 | 地域、家族、姓名、灵根、资源、重抽与改名 | 更多出身和家族故事 |
| F02 时间 | 年月、暂停、速度、逐年、快转、按重心随缘回应、世局 | 更丰富年代设定 |
| F03 指标 | 体魄、心境、悟性、修为、技艺、牵挂、重心与年表曲线 | 更清楚的变化拆解与愿望对照 |
| F04 修行 | 功法、灵根效率、积累、突破、失败、伤势、寿元、飞升 | 更完整劫难、流派与特殊修法 |
| F05 学习职业 | 启蒙、师承、四类谋生与统一技艺 | 独立炼丹、炼器、符阵技能树与配方 |
| F06 关系 | 父母或抚养人、同伴、伴侣、孩子、师徒、照护与离世 | 亲族、同门竞争与更长关系故事 |
| F07 经济资产 | 铜钱、灵石、灵草、收入家用、欠账、住处、旧物 | 田产、产业、价格与继承分配 |
| F08 物品行动 | 买卖、疗伤、符的消耗、常用物品自动生效 | 赠送、实例化装备、维护与任务 |
| F09 地理迁移 | 五处地域、路资、月份、抵达和足迹 | 更多路线、迁居生活与秘境 |
| F10 世界势力 | 世局、天气、繁荣、风险、组织积累与负责人交接 | 派系关系、制度、领地与完整战争 |
| F11 同代人物 | 同伴独立去处、修行、寿元、道路记录 | 同代多人物曲线与深入对照 |
| F12 抉择故事 | 22 类故事、动态修行抉择、条件选项与两类延迟后续 | 地域、职业和不同境界的长篇连续故事 |
| F13 风险终章 | 伤势、失败、寿终、飞升与八类终章 | 更多具体原因与各条未尽之事 |
| F14 愿望回顾 | 关键抉择、年表、人物记忆、前世与未完人生 | 自选愿望和更细致的取舍回顾 |
| F15 展示传记 | 私人 HTML 传记和纪念卡 | 公共传记、访问和反应 |
| F16 洞府 | 四类外观、常用物品与同住者画面、闭关 | 自由摆放、设施与更多活动 |
| F17 分享纪念 | 出生／当前／终章 PNG，HTML、CSV、JSON与打印 PDF 路径 | 相册、独立 PDF 生成器、视频与电影回顾 |
| F18 存档转移 | 独立完整本地档案、版本校验、备份、冲突并存、JSON 转移 | 云备份与账号同步 |
| F19 社区统计 | 未实现 | 投稿、回应、删除举报、分页与真实统计 |
| F20 世界实验 | 内核支持固定种子，测试使用明确策略进行采样 | 面向用户的实验与比较界面 |
| F21 权益支付 | 当前免费本地游玩 | 是否收费与渠道尚未确定 |
| F22 基础能力 | 帮助、版本说明、主题、减少动态、可选山音、响应式、原生按钮与键盘 | 更多语言、Safari/Firefox 与 iOS/Android 真机验证 |

下一轮优先 W3–W5：先用一条完整的炼丹／炼器职业故事验证配方、经营、师徒和遗产，再扩展宗门竞争与秘境旅行。新增故事直接进入当前人物的普通抉择和年表。

存档、规则和内容版本需与交付证据一致。正式升级前为旧档建立可重复验证的迁移案例。公开 GitHub 写入、合并和部署以当次任务授权为准。
