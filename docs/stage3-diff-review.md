### ② 表达域：事实一个没变 ✅

`node scripts/t7-diff.mjs --before=<HEAD 版> --allow-added='background_*,sect_department,method_choice,*_joint_settled,*_joint_pending,*_joint_hidden'`

```
✓ 变更前有的卡一张都没少（少了 0 张）
✓ 变更后没有多出规则层没有的卡（多了 0 张；另有 35 张是**声明过的新增卡**）
✓ 每张卡的选项数都没变（变了的 0 张）
✓ 正文里的数量一个都没变（变了 0 张）
✓ 提示语里的数规则层本来就知道（编出来的 0 张）

```

⚠ **35 张新增卡是声明过的**（12 背景 + 2 入门环 + 21 接头卡）。
`--allow-added` 是**必须显式声明**的口子；不声明时照样报红
（反向验证：不给 `--allow-added` ⇒ 「多了 35 张」⇒ 退出码 1）。
