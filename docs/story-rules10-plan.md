# 本轮完整剧情审查与优化计划

日期：2026-11-04。范围：独立 HTML 试玩，不实施小程序、不修改生产 Web、不部署或合并。

执行状态：本轮八步已完成。最终205项测试、600次全剧情审查、另400次多路线模拟及23阶段回归均通过；源码和静态构建分别完成5条本轮专项浏览器人生。详见文末与验收台账。

## 审查结论

当前故事由童年标记、五条人生道路、宗门／散修／魔修／妖修长事件、师承邀请、家庭消息、高阶材料与战后发展组成。问题并非各张卡独立出现：灵根只有积累倍率，人物分散存储，长事件统一生成后续，导致能力、人物介绍和前次选择不能稳定约束后续。

本轮按全部当前决策事件、自动经历池和完整人生检查，生成逐事件审查台账。需要区分静态检查、自然人生覆盖和受控分支验证；未被实际执行的路径不能写成试玩通过。

## 全局故事范围与处理依据

| 范围 | 审查发现与本轮处理 | 保留的后续工作 |
| --- | --- | --- |
| 出生与童年 | 出生资质必须约束成年能力；童年旧友、铜匣、旧师与商队分开追溯，保留同一局的随机姓名 | 幼年不同出身的更多生活细节 |
| 测灵、入宗与谋生 | 未显灵根原来仅减速，仍可走普通授业和晋升；改为复测、劝退／回乡、凡俗杂役及药铺手艺 | 更丰富的凡俗职业与亲属结局 |
| 心法、考核与晋升 | 普通心法须引气资格，法力行动须实际境界；御剑授业不能出现在尚未炼出法力的获奖说明中 | 各属性功法与灵根的精确适配，普通剑技和法术进一步分栏 |
| 护山阵、宗门争水 | 执事和长老应说明角色为什么被派遣、谁判案、谁能商定灵泉；证据和奖励按实际调查结果产生 | 失职者与邻宗人物的长期记忆、报复和再会 |
| 宗门试炼与散修遗迹 | 谷口照看补给、留在洞外、协助看阵都是有效出口，不能强行进入下一个危险场景 | 退出后的新委托与其他队伍的结果反馈 |
| 跨大陆与旧约 | 来信、核实和拜访不是同时完成；按可达商路送达和赶路，暂缓或战乱后有继续入口 | 更多路线失效原因与可信的替代联系人 |
| 运棺与旧案 | 交代委托人与死者关系；驿站留棺、桥头弃车和送回故乡分别记录，不把血字当作无条件定案证据 | 旧案的多种真相和长期追索 |
| 魔修药库、禁术与转师承 | 保留规则9的借卷、证据追责与交换合同；本轮限制无根绕过，摄血后续区分草药、兽血和囚犯血 | 权限、囚犯身份及长期代价的更多非固定分支 |
| 妖族栖地、化形与袭击 | 真实出生妖身与仅改变道路标签分开；是否服药、是否先撤幼兽约束后续 | 妖族人物寿命、栖地发展与人族关系 |
| 家庭、战后重建与高阶 | 保留实际运输、公共资源及材料晋升合同；新旧友消息不抢占当前长事件，无根者不进入高阶修炼任务 | 长寿角色的关系更替、闭关期间世界变化与阅读节奏 |
| 自动经历、人物与存档 | 凡俗经历使用有限具体故事；重要管理者与联系人接触后可查，正文介绍职责；旧事件表与执行器独立 | 匿名临时人物不必全部入册，长期人物需更完整状态和离世处理 |

当前事件表含205张决策卡，其中包括突破尝试、材料差事和战后恢复的独立事件ID，并非205条互不相干的故事。其中selection_3／4及其结果由旧内容安装过程生成，新人生调度已排除这些高阶基础考核；统计时不把它们当作必须自然到达的剧情。16条三阶段长事件只是整体故事网络的一部分。全表结构检查与自然到达统计解决的是条件、关联和执行问题；不能用字数检查代替逐分支文学质量评价，也不能用自动选择推断真人理解和留存。

## 实施顺序

1. 冻结规则9事件及执行模块，保存改动前生成的继续执行基线。新人生用规则10，旧档保留规则及随机流；基线明确标注为引擎生成，不伪称玩家导出。
2. 建立统一修炼资格。未显灵根在复核之前不能引气；复核可以确认无灵根，少量有前因的检测例外才发现隐蔽灵根。无灵根保留凡俗剑术、识药、经书知识与谋生，关闭常规心法、御剑、属性法术和突破。妖身必须有实际出生或后续身体改变的来源，不能以改变路径标签绕过限制。
3. 补上无灵根人生。检测不成功者可回乡、留宗做凡俗杂役或去坊市谋生；手艺考核可以获得非修炼职位和报酬。日常经历、收支、功法邀请、危机及结局与凡俗能力一致，洗脉丹与摄血法不能凭空造根。
4. 将旧渡口合并卡拆为旧友重逢、铜匣来历、旧师／商队消息。记录消息来源及跨地域送达，核实、拜访、兑现分别推进。暂缓保留实际可继续的阶段，放弃结束本次机会；已有功法者不再重复基础拜师。
5. 统一人物介绍与可查询关系。重要人物第一次出现说明作用，重要管理者与长期故事联系人在接触后进入“人物与牵挂”。稳定姓名、职责、已知信息与人物状态来自同一记录，不预先公开未遇见者。
6. 修正全局长事件的因果。重点为争水证据、运棺交付、遗迹／跨界的未入场分支、禁术是否实际练过、化形是否真实服药，以及重建责任。无前置事实的选项关闭或改成成立的行为，失败／退出保留真实状态，不把互斥选择强行接回成功正文。
7. 专项测试：灵根与法力边界、三条童年后续、暂缓与消息中断、人物首次出场、长事件分支与旧9继续执行。再跑适当的完整回归、自然人生模拟与源码／静态浏览器核实；视觉沿用当前组件和像素画风。
8. 完成后补充本轮实际结果与下一轮建议。次轮优先级来自剩余实测问题；不声称自动策略证明真人留存。

## 设计边界

- 普通技能与灵力施法不是同一能力；阅读一本书不等于会施法。
- 本轮不增加人人必得的造根、夺舍或无门槛禁术改命机制。
- 对手修为和身份在决策需要时交代，不展示后台成功率。
- 人物介绍保持简短，故事仍保留未知意图与危险，不能因解释规则而写成操作说明。
- 故事可以失败或结束，不能为了凑满三个阶段让没发生的调查、入洞、服药自动发生。

## 验收

没有引气资格的完整人生不会获得常规修为、御剑授业或修炼弟子职位。三种童年前因各有实际后续，暂缓确实能够继续。争水不查证时不生成角色发现的刻痕，未跨界者不遭遇异界专属事件。人物详情可查到已经接触的重要人物，首次卡片无需打开详情也能理解。旧9基线继续执行逐值一致，其他历史档检查仍通过。检查结果与未覆盖项目在台账明确列出。

## 实施补充

完整人生审查发现，新加的凡俗路线耗尽早期经历后，部分角色从38岁到70岁没有新记录。已增加少量中晚年自动经历，按最熟练的实际手艺、是否收到过家书与年岁区分；仅在没有长事件、看管或禁闭的安静时段出现，同一生不重复。不强制每年一条，不为填空重新开放修士路线。

无灵根人生另有“灯火人间”收尾，不使用已继承魔道／妖族传承或留下修行法门的结局说明。谋生考核成功的职位与经历计数分开，取得熟手岗位不会跳过第一条谋生事件。
