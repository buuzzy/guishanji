## 二、有意改的、可能让玩家觉得「怎么变了」

这几条是**有意**的，不是副作用：

1. **立身×金丹 / 传灯×金丹 的内容按年龄窗口走** ⇒ 与「金丹 95–150 岁」冲突时以窗口为准
   （S4）。
2. **新增了第四张突破卡**，并按境界分档调了成功率和耗时参数（S4）。
3. **新增「体魄」；失败不再扣体力；虚弱改成临时状态**（体力恢复了就消失，不是永久残疾）（S5）。
4. **长线改成「该发就发」**（S6）⇒ 同一路径上的几条长线会互相让位，
   有些人生某条线抽不到机会；魔道路线玩家更早卷入冲突、**可能死得更早**。
5. **宗门供料年限从「按宗门强弱」改成「按自己的筑基窗口 42 岁」**（S6）。
6. **表达域纯重构**（S7）⇒ 一个字都没改，但文件从 1 个变成 13 个。
7. **呈现域有意变更**（S8）⇒ 顶栏新增「寿尽 X 岁 · 还能活 Y 年」；地图改成只画当前所在 + 走过的大陆。
8. **内容模块拆分**（S9）⇒ 纯重构，内容一字未改。

## 三、S10 全量回归抓到的问题（已修）

### 3.1 地图上的「路」几乎看不见了

**现象**：`decision-browser` / `decision-static` 两道门禁红了
（`'0' !== '4'`：地图上的通路条数不对）。

**根因**：S8 把地图改成「只画当前所在 + 走过的大陆」，
**顺带把「通路」也按同一个条件过滤了** ——
两端都走过的大陆之间才画路。

**实测有多严重**：画面门禁里随机模拟出来的 5 段人生，
**每一段都只在一块大陆上**（`visited` 只有出生地）
⇒ 地图上其实**一条路都没有**，图例里「虚线 · 已知通路 / 墨绿 · 已走路线 / × 暂不通行」三条全都用不上。

**这次怎么处理的**：

- **地图本身没动**（保持 S8 批准的设计）。
- **门禁的判据换严了**：原来写死「4 条通路」，现在**从存档独立算一遍**
  （当前所在 + 走过的大陆 ⇒ 之间的通路条数），再跟地图画出来的比对。
  ⚠ 故意**不**调用规则层的 `mapView`：两边同源就等于自己跟自己比，地图画错了也看不出来。
- 顺带守住「当前所在」：地图标的位置必须跟存档一致。
- 画面门禁也加了同口径的「通路条数」断言，并**补了一段「走过两个大陆」的人生**
  （否则那条断言是 0 == 0 的空跑）。

**反向验证四道全报红**：地图多画通路 / 少画通路 / 标错当前所在 / 通路数写死成 4。

> ✅ **已按你选的「甲」改完**（2026-11-07）：规则层的 `mapView` 现在给的是
> 「当前所在 + 走过 + **从这些地方能直接去的大陆（只隔一跳）**」。
> 在青岚就看得见临潮与烬原，也看得见通往它们的路（路暂时不通的照样标 ×）；
> 隔两跳的大陆不画（浮屿界在青岚看不到）⇒ 地图依旧聚焦；走过的路越多，画出来的大陆越多。
> 改完实测：出生在浮屿界 ⇒ 画出浮屿界 + 临潮 + 烬原两块相邻大陆 + 两条路 ✓；
> 出生在青岚 ⇒ 画出青岚 + 临潮 + 烬原 + 两条路 ✓。
