- **① 扫码权限**：预览码只对 **30 名「开发成员」**有效。若扫码提示无权限 ⇒
  需在微信公众平台「成员管理 → 体验成员」里加上这个微信号（体验成员最多 15/50 名，看主体类型）。
- **② 预览码时效**：官方口径「十几分钟」。过期找我重出一张即可（走真实编译流程，约 1–3 分钟）。
- **③ 首次进入会等一下**：从官方首页点「归山记 · 修仙人生（实验）」，微信要先下载
  **engine 分包**再下载 **xianxia 分包**（两段下载）⇒ 头几秒可能是空白，**不是白屏 bug**。
- **④ 官方人生不能受影响**：修仙是独立分包，存档写在 `xianxia.v1.*`，与官方人生
  （`one8b.*` / `o8b.*`）完全分开。第 22 项专门验这条。
- **⑤ 倍速档位**是 1 / 2 / 4 / 8 / 12 / 16 六档；**自动抉择默认关闭**。

## 六、边界与已知现象（不是 bug，别记成 bug）

- 首次点入口要等两段分包下载 ⇒ 几秒空白属正常。
- 修仙存档在 `xianxia.v1.*`；官方人生在 `one8b.*` / `o8b.*` ⇒ 两边各存各的，**不会互相污染**，
  也**不会**在两个小程序之间互通（微信按 AppID 隔离缓存）。
- 修仙线**没有**：联网、分享、追思馆、跨端导入、HTML 档导入、反馈表单、导出存档。
- 自动抉择默认关；打开后是公开策略，不会偷偷替你挑最安全的那条。
