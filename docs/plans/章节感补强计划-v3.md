# 归山记 · 章节感补强计划（规则十二 · 体验轮）v3 完整版

状态：**已执行完成（2026-11-08 晚）**——全量回归 38 道门禁全绿（REGRESSION PASS），小程序包已重建。执行结果与验收数字见文末「十三、执行结果」。

## 一、设计原则（本轮及后续所有轮次的总纲）

出生决定起点，经历制造差异，境界划分章节，突破结算过去。
章节 = 境界：凡身章、炼气章、筑基章、金丹章、元婴章。年龄只负责寿命压力和世事变迁，不作为剧情的主坐标。
修行起点 = 得到功法或心法：与年龄无关，与在不在宗门也无关。
每章闭环：获取 → 保存 → 决策 → 消耗/汇流 → 突破时清算。
跨章只带人生级变量：境界、功法、法术、关系、伤势、誓言、核心信物。阶段道具不跨章。
凡尘线与仙路并列：凡尘线不算失败分支（本轮只做守护，下一轮补内容）。

## 二、本轮要解决的痛点

节奏忽快忽慢；
故事散乱，缺乏章节感；
缺少冲突和张力；
入门后很快就突破炼气初期，而且有灵根但没入门的人也在攒进度（源码已核实）。

本轮定位：炼气章原型。把一章完整的闭环跑通一次，后续各章照着复制。

## 九、风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 门槛和窗口不同步 ⇒ 慢速命被强制低进度早突破 | 两者一起按实测定档（3c） |
| 炼气章 4 张卡加日常卡超出密度上限（十年 ≤8） | 炼气章进度约筑基门槛 120 点 ÷ 约 7 点/年 ≈ 十余年，4 张确定性卡分散其中压力小；阶段三实测，超限就减日常卡的权重 |
| 奇遇卡变成必选深入 | 失败有实际代价，另外两个选项有保底收益；阶段三统计三个选项的选择率作为观察项 |
| 闭关、待选期间的卡被吞或重发 | 顺延加阶段记账 |
| 清算误删重试要用的主药 | 只在离开本章时清算 |
| 清算旁白消耗随机数 | 只走日志通道 |
| 志向透传影响经典档 | 经典档显式回归用例 |
| 结局门禁被 C1、C2 打红 | 阶段三统一重新定档 |
