# W1 卡稿 · 同期弟子三人（v3 · 两轮评审修正完毕，可进引擎）

> 读法：每张卡按「标题 / 正文 / 选项」给全文，玩家读到的就是这些。标 ⚙ 的是机制注记。
> v3 处置了第二轮评审的三个自相矛盾与五个重要问题，处置对照见第十三节。

## 一、背景

章节感补强轮验收后拍板：骨架保留，故事层重写，从凡身到炼气分段推进。重写规范五条：一拍一卡、有后果、有回响、朝章节终点积累、人物带职责出场。本篇是第一段，同期弟子系统，文本定稿后进引擎。

## 二、分析结果（摘要）

四个根子问题：同期弟子不存在；长线与筑基零关联；NPC 只有职务没有人；后果量级不统一。拍子级重复有实测支撑：「测灵」一拍被三张卡在三年里讲了三遍，玩家把「把手放到测灵石上」读了四次；一百二十条命扫描，同月硬重复中位每命一点五处。场景与卡的分工规矩已立并在 W0 落地：场景只写卡里没有的氛围，制度拍子只归决策卡讲，本月有卡要发时场景让位，重复讲述已降至每命一处。

## 三、结论与设计判断

三个同门各扛一面镜子：岑野是比你快的人，石瓮是比你慢但稳的人，小满是离开的人。四张卡加一张登场，各认领一个拍子：面、备、别、信、根。后果全部落在状态上，回响两轮评审后全部接线闭合。路线条件统一为：登场卡看出身，其余看当前是否仍在宗门。

## 四、人物小传

**岑野**——镇上药铺掌柜的独子，本可以继承铺子。测灵那天，他把手放上石头之前先问了一句「测完之后呢？」。三相灵根，同批里第一个把名字写上进道名册的人。他的快是真的，他的茫然也是真的。问道之镜。

**石瓮**——货郎的儿子，五行杂灵根，按宗门规矩入的是杂役。名字是爹按体格随手取的。练什么都慢，所以每天比你多练两个时辰——用他的话说「我又不赶时间」。山门里谁都使唤得动他，他也乐意。守护之镜。

**小满**——农家女，家里排行第三，测灵日排在队尾，因为要等家里借到驴。入道第二年的秋信到：弟弟入秋咳血，家里想把她换回去。她的行李永远打成随时可以走的打法。凡尘之镜。

## 五、第 0 张 · 测灵日登场（随本段落地，不再等 W2）

三个人的名字在测灵那天立住——各一句，按条件写进山门卡的正文：

- 岑野一句：队伍中段有个少年，轮到他之前先问执事「测完之后呢」，问得执事抬眼看了他一下。
- 石瓮一句：有个宽背少年在帮排在前头的人扛行李，扛完自己站回队尾。
- 小满一句：队尾还站着个姑娘，脚下放着一捆铺盖，等人牵驴来替她驮。

⚙ 触发按**出身**：宗门路出身即显示。散修、幽灯堂、妖身出身的同门线本轮不做，登记为缺口，留下一轮。⚠ 登场卡随 W1 落地：卡一选项三的提示语依赖这次登场，两者必须同批上线。

## 六、卡一 ⚙「同批里的第一个」——岑野已入道而你还没有时发（一次）

⚙ 触发：**当前在宗门**、已获心法、岑野已入道（固定 18 岁）、玩家未入道 ⇒ 卡落在玩家的凡身章后段。玩家若先入道，本卡不发，卡四的追加句随之自然缺席。

**正文**：入道名册换了新页，同批里岑野第一个走了出去。演武场那头，他走剑的动作干净得像抄好的字。有人替你叹气，也有人说风凉话：同一天测的灵，人家头一年就走在前头了。

| 选项 | 提示语 | 回话 |
| --- | --- | --- |
| 当面贺他一句 | 实话实说，不酸。 | 你走过去说了句恭喜。他愣了一下，问你晚上有没有空。两个人在饭堂坐到熄灯。他讲了他爹的药铺，讲了他爹想让他接秤。至于为什么修，他没提。⚙ mind+2 |
| 回屋加练一个时辰 | 进度是真的，心也是真的累。 | 你把晚课挪到子时，当月的功课比往常多攒了一截。演武场的灯灭了，你屋里的灯还亮着。⚙ 该月进度+2，mind-2，标记 rival |
| 问他为什么修 | 排队那天他就问过执事一个问题，你想听听他的那版。 | 他想了很久，说他爹的秤称得出药贱不贱，称不出人值不值。说完他自己笑了，说这不算答案，等有了答案第一个告诉你。⚙ mind+2，标记 askedWhy——筑基冲关前兑现 |

⚙ 触发：**当前在宗门**、realm 为一、本章进度达到百分之四十五。本卡按「代价冲突」登记进冲突标签表。

**正文**：小满的包袱打好了，是那种随时可以走的打法。家里的信摊在石阶上：弟弟入秋咳血，家里想把她换回去。她问的不是准不准，是「你们说我修到这一步，值不值当」。

## 九、卡四 ⚙「出发之前」——筑基冲关前发（一次，两个维度：去留定主体，问为什么定追加句）

⚙ 触发：**当前在宗门**、realm 为一、本章进度达到八成半。卡三发过才发；卡三没发过（极端命）则本卡跳过，不留悬空引用。

**主体按去留分两版**：

- **她走了（搬行李 / 陪坐到天黑）**——卡名「商队捎来的消息」：
  正文：商队带来小满的口信。弟弟好了，家里让她别再惦记；她跟着舅舅学认牲口行情，说这行当离不了人。
  选项一「托商队回一封信」：这些年的第一封写满一页的信。你写完读了一遍，没有删。⚙ mind+2
  选项二「把口信收进心里，继续备料」：冲关要紧。你把口信折好压在卷册最底下。⚙ insight+1
- **她留下了（捎钱与药方）**——卡名「石阶上的晚饭」：
  正文：小满端了两碗饭来找你，说练完了也是吃，不如一起。她问山上的日子你还惯不惯，问得很轻，像是替信里那个弟弟问的。
  选项一「陪她把饭吃完」：两个人把饭吃完，谁也没提那封信。⚙ mind+2
  选项二「把碗还她，继续抄单子」：冲关要紧。她把碗摞好带走，走到院口回头看了一眼。⚙ insight+1

**追加句·问为什么（仅有 askedWhy 标记时，接在任一版本正文末尾）**：

> 出发之前，岑野来过一趟。他说那个「为什么修」，他大约想起了一点——没说透，只说等你出关，两个人对一对答案。

**追加句·较劲（仅有 rival 标记时，同样接在正文末尾）**：

> 岑野在演武场等你，说这回该你先走了。

⚠ 机制注记：「为什么修」的完整答案留到筑基篇兑现，已在缺口台账登记（「岑野的答案」，随筑基卡稿交付）。
