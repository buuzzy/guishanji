# 山海一生 0.1.0 · Web 首版交付

2026-10-25 完成首个本地可玩版本。打开 **http://127.0.0.1:8866/**，从首页开启一世即可经历成长、修行或谋生、牵挂、世事、终章与前世录。故事直接进入当前人物的抉择、资源、关系和年表，无需另开扩展模式。

这是路线图 W0–W6 的基础可玩闭环，覆盖本地构建验收；各领域的完整扩量和 W7 公共能力仍在后续计划中。实际状态逐项列于 [Web 路线图](web-roadmap.md)。

## 可体验的内容

- 五处地域、五种出身、四类灵根、三类组织、六层境界及八类终章。
- 出生重抽、改名、整数月推进、年度快转、自动流转、速度与暂停。重要抉择使推进停下，回应后继续。
- 22 类原创故事、11 个年龄节点及动态突破／飞升抉择。相助之后的承诺、离世之后的旧物具有延迟后续。
- 修为、功法、灵根效率、突破准备、成功与失败、疗伤和寿元。突破选项显示游戏内的机会和成本。
- 药师、匠人、行商、田户的收入、家用、债务与资源交易。书、剑和符等已持有物品自动参与适用的日常规则。
- 具有独立 ID 的父母或抚养人、同伴、伴侣、孩子、师长与学生。亲友选择去处、修行、成长和离世；组织负责人交接。
- 按月旅行、地域繁荣与风险、1／3／5／10 年闭关。亲友和世界在闭关期间继续变化；要事暂停，转向其他生活重心则提前出关。
- 原创 Canvas 山水、人物、地图和四类住处外观；日色／夜色、减少动态与用户主动开启的原创合成山音。
- 出生、当前人生、终章 PNG 留影；HTML 传记、CSV 年表、JSON 人生或全量档案。HTML 可离线打开，并通过浏览器打印为 PDF。

此世界、数值、概率和寿元为原创架空设定。来源与技术边界见 [原创与参考记录](provenance.md)，具体规则见 [世界设定](world-bible.md)。

## 存档与版本

游戏版本 `0.1.0`，规则 `shanhai-rules-1`，内容 `shanhai-world-1`，存档格式 `1`。命名空间为 `shanhai.life.v1`，和参考项目分开。

同一份完整档案保存所有已结束和未结束的人生。每次成功写入前备份上一份完整档案，并读回检查。配额不足、损坏、未知版本与其他页面写入冲突会保留已有数据并提示处理；本页尚未保存的进度仍可导出。

同一人生的不同进度可先预览，再将文件进度作为副本并存。副本重写人生与人物引用，保留姓名、年月、机缘与经历。恢复备份前保留原始文字，原档可在页面下载。升级前须为此正式基线维护明确迁移行为。

当前采用浏览器本地档案；跨设备使用 JSON 导出与导入。清除站点数据会移除浏览器保存的内容；切换站点、端口或浏览器前，应下载全量档案。

## 本次验证

环境为 Windows、Node 22.22.2、Chrome 155.0.8059.40。手机验收为 Chromium 触控与视口模拟，含 360／390／768／1280 宽度；没有把这些结果当作 iOS 或 Android 真机结论。

| 验证 | 结果与实际范围 |
|---|---|
| 静态检查 | 27 个 JavaScript 模块的语法、导入路径、大小写与 LF；22 类故事结构和出生状态 |
| 引擎及存档 | 31 项通过：19 项引擎、12 项存档 |
| 人生策略采样 | 56 条完整轨迹，七种明确策略各八条，覆盖七类自然可达终章；40 次突破成功、1 次失败 |
| 浏览器 | 26 项通过：普通出生至终章、刷新恢复、修行与闭关、交易、导出、多页面冲突、坏档恢复、配额故障、触控、布局与键盘 |
| 实际静态构建 | 3 项通过：21 个清单文件／231,042 字节全部核对 SHA-256，20 个公开文件及首页 HTTP 响应一致，构建页面实际完成出生至抉择回应和刷新 |
| 文件产物 | PNG、HTML、CSV、JSON 实际下载，传记实际离线打开并打印为 PDF |
| 浏览器资源 | 应用页面无 JavaScript 错误、失败响应或外部网络依赖 |

采样的修行策略明确使用清灵根，其余六种策略使用未见灵根；这些结果证明相应路线可达，不是全体玩家的自然概率。伤势终章另以受控伤势和实际随机失败检验，不能与七类自然采样混算。

调试期间发现并修复了六岁学艺的条件、修士职业／晚年选择的修行延续、闭关转向时退出、离世人物年龄、账册负零序列化、最高境界非法递增和离世人物关系条件等问题。还完善了同人生文件冲突并存、恢复原档下载与当前人生留影入口。

浏览器验收曾因模态框与背景按钮重名、首月闭关遇到突破，以及多页面失败写入尚未结束时过早点击重读而失败。已修正实际点击目标和对应等待条件，完整回归通过后形成 [验证摘要](web-verification.json)。原始运行报告、截图、文件和失败记录保留在本机忽略的 `artifacts/`、`.local/`。

## 运行、构建与本地版本

项目为原生 ESM／HTML／CSS／Canvas 2D，无第三方运行依赖。运行与校验命令见 [README](../README.md)。

```sh
node scripts/serve.mjs --port=8866
node scripts/run-regression.mjs
node scripts/build.mjs
node scripts/verify-build.mjs
```

`dist/` 为静态站点产物，需从站点根目录发布，并保持 `/apps/web/`、`/packages/`、`/content/` 路径。本地可通过 `node scripts/serve.mjs --dir=dist --port=8867` 打开。构建、日志、临时 profile 与本地服务记录均不入库。

本轮使用独立项目与 `feature/web-prototype` 本地分支。参考 1in8b 仓库仍为 `1984cee21c639729f6885e21e7ba89b325ef824d`，检查时工作区干净。本轮没有向 GitHub 写入、合并或公开部署；新项目未配置远程。
