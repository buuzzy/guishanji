# 纯 Web 实施路线图

用户于 2026-10-25 要求做 Web 并开始实施。此文覆盖先前双端方案；本项目后续仅保留 Web 的产品、构建和验收任务。

0.1.0 已完成基础闭环；**0.2.0** 继续补入道指引、地域活动与迁居抉择、资源链、丧亲过程、事件去重及世局。原型仍是同一段人生，不需要开启扩展模式。后续按下列阶段继续扩展。

| 阶段 | 交付内容 | 当前状态与下一步 |
|---|---|---|
| W0 世界与来源 | 规则、原创边界、目录与数据契约 | 首版基线已实现并落档；扩展内容持续审校 |
| W1 人生与持久化 | 月时钟、RNG、实体、队列、条件、版本与安全存档 | 核心已实现；新版本继续维护迁移契约 |
| W2 完整人生 | 出生、成长、选择、终章、年表与前世 | 可玩闭环已实现；愿望回顾待补 |
| W3 修行与生计 | 突破、失败、职业、资源、物品与家缘 | 明确入道、通窍、兑换、养元丹和住处加成已接入；多配方、炼器、符阵和产业仍待扩展 |
| W4 活世界 | 地域、势力、同代人物、迁移与时代事件 | 五地活动、定期迁居及 11 类持续世局已接入；继续补派系制度、外交、秘境与同代曲线对照 |
| W5 故事与视觉扩量 | 多地域故事、活动表现、完整洞府编辑、移动布局与声音 | 43 类故事、部分变体、冷却、素服与纪念画面已接入；需要更长故事链和更多人物活动 |
| W6 回顾与转移 | 分享、传记、详细回顾、纪念展示与跨设备存档 | PNG/HTML/CSV/JSON、打印路径和本地转移已实现；视频、相册与云备份待实施 |
| W7 公共能力 | 公共传记、社区与实际统计，按需商业化 | 未实施；先确定新产品的后端、账号、数据范围和发布方案 |
| W8 Web 首发 | 内容验收、平台回归、版本锁、静态部署与回退 | 本地引擎、Chrome／手机视口与实际静态构建验收通过；公开发布和跨浏览器／真机验收尚待完成 |

根据本次 [公开机制研究](feedback-research.md)，下一阶段按以下顺序推进。均为待实施任务，不将当前的一枚丹药、一次器坊差事或遗迹事件视作完整系统。

| 顺序 | 下一阶段内容 | 交付条件 |
|---|---|---|
| P1 修行与职业故事链 | 增加丹方和独立熟练度，师徒授业、订单、失败返工、作品与遗产贯穿多年 | 凡人能靠职业获得入道准备；材料、月份、产物和去处全部解释清楚 |
| P2 宗门与功法 | 入门、贡献、任务、传授、同门竞争、离宗与负责人变化 | 宗门职责消耗时间、有收益与关系后果；旧师承与已学功法可继续读取 |
| P3 秘境与远行 | 准备、探路、分段探索、退出、遗迹、宝物辨识与同行者 | 不只滚一次随机数；风险、时间和返回路径可见，途中允许退出 |
| P4 地域与长期世局 | 药材和工坊需求、不同价格、赈济恢复、战争与势力后果 | 玩家所在地方、职业与亲友实际受影响；避免所有地方只换名字 |
| P5 群像与视觉 | 更长的亲友承诺、迁居后的家庭、同代道路、场景活动和纪念展示 | 人物身份、生死、地点和旧承诺一致，所有内容仍在同一人生内 |

每一阶段先维护迁移与回归，再继续扩量。云存档与公共能力在玩法稳定后按 W7 单独实施。

存档、规则和内容版本需与交付证据一致。正式升级前为旧档建立可重复验证的迁移案例。公开 GitHub 写入、合并和部署以当次任务授权为准。
