# 归山记 · 故事重写计划（凡身 → 炼气篇）v1

状态：**待拍板**。拍板后按 W0 → W6 逐段执行，每段完成后暂停过目，确认再进下一段。

## 一、这一轮解决什么

用户判断（2026-11-09）：章节节奏已达标（v3 轮成果），但故事层要重写。经分析，凡身→炼气段的病根有四个：

1. **同期弟子不存在**——文案引用「同批上山的人」，游戏里没有任何一个同门角色；玩家孤独地上山、孤独地闭关。
2. **长线与筑基零关联**——护阵、搜救、争水打完，对冲关没有任何积累。
3. **NPC 只有职务没有人**——许执事、严衡出场就派活，没有私怨私恩。
4. **后果量级不统一**——童年/入门选择只动心情数值 ±3，新卡后果是修为折损两成、受伤、道具。

另有一个本轮新发现的结构病：**拍子级重复**——「测灵」一件事被三张卡在 14–17 岁间讲了三遍（child_recruit「问清测灵」→ reception「山门外的队伍」→ root_result「测灵石上的记录」），玩家三年内四次读到「把手放到测灵石上」。实测同月硬重复（≥10 字共享片段）每命 1.5 处。

**明确不动**：引擎、门禁、章节节奏（门槛/窗口/排期机制）、清算、冲突标签——v3 轮骨架全部保留。**本轮范围**：凡身章 + 炼气章的故事层。金丹/元婴章内容、凡人线补全，留下一轮。

## 二、重写规范（每张重写的卡都要过这五条）

1. **一拍一卡**：一个制度/剧情拍子只由一张卡讲透，讲过不回头。入门串五张卡按下表认领拍子。
2. **有后果**：选项后果落在状态上（修为、伤、道具、人物关系、标记），心情数值只作辅料。
3. **有回响**：本卡埋的线（人物、物件、承诺）必须在后续卡或旁白里兑现。
4. **朝章节终点积累**：炼气章内的经历要留下通往筑基的一样东西（人脉、材料线索、领悟之一）。
5. **人物带职责出场**：有名的人物首次出现必须交代他是谁、与你何干；NPC 要有私心。

**场景与卡的分工**（2026-11-09 截图分析得出的规矩）：场景旁白只写卡里没有的氛围，**不许预演任何待发卡的内容**；排队、测灵、录取等制度拍子只归决策卡讲。机制配一个小修正：本月有结构性卡要发时，场景通道让位。

## 五、验收标准

1. 打重门禁：同月重复讲述从 1.5 处/命降到 **≤0.5**；「测灵」拍子全段只出现一次。
2. 人物：一条修仙命 24 岁前至少与三个同门各有一次具名互动；三个同门在收官文里可被引用。
3. 长线：三条宗门线走完各留一样筑基积累（道具/加成/引荐），触达门禁保持全绿。
4. 规格五条全过（一拍一卡 / 有后果 / 有回响 / 朝终点积累 / 人物带职责）。
5. 全量回归 38 道 PASS；叙述:决策 ≥ 6.3；首突破/筑基节奏数字不劣化（中位 21–24 / 36）。
