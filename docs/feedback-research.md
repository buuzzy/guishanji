# 试玩反馈、修仙机制与丧礼研究

本轮针对用户提出的 11 个试玩问题，先补齐“看得懂下一步、行动确实发生、结果进入此生”的规则，再用公开修仙游戏机制安排后续扩展。研究与实现范围为独立 Web 项目山海一生。

2026-10-25 使用现有搜索 REST 服务搜索，并通过 contents 接口取得下列网页正文。结论依据官方商店介绍与政府/学术资料；没有实际游玩竞品、审查其源代码或验证它们的全部数值。Steam 社区攻略仅作为线索，不用玩家观点冒充官方结论。

这些公开介绍支持“财、侣、法、地、时间彼此关联”的设计方向，不能证明任何一套具体公式就是修仙游戏的唯一标准。0.2.0 的 12 点引气、通窍、费用、兑换与突破概率均是原创参数；没有照搬竞品的丹方、流派、故事与数值。

当前形成的可玩流程：在同一人生里学调息与积累引气，靠职业、采药、修器和交易准备材料，完成入道，然后按所在地与住处条件修炼。旅行有自然询问和真实月份；亲友在此期间独立成长、迁居或离世，世局持续影响谋生和修行。

更完整的宗门贡献、独立技能、多丹方、分段秘境与派系战争列在 [路线图 P1–P5](web-roadmap.md)。本次没有宣称已完成这些完整系统。

## 传统丧礼的依据与边界

| 资料 | 可支持的事实 | 本作的处理 |
|---|---|---|
| [宁县政府《农村丧葬礼俗》](http://www.ningxian.gov.cn/yxnx/wmnx/mswh/content_15817) | 当地资料介绍埋葬与周年，说明“亲属穿丧服叫‘成服’”，并引述奔丧、成服 | 采用亲属身份、返乡、成服、安葬与周年的先后安排；不复制当地所有具体仪程，不将其说成全国统一做法 |
| [付驥瀟，2019，《“禮各有主”與差序格局》](http://www.shehui.pku.edu.cn/upload/editor/file/20201104/20201104135737_4036.pdf) | 对《仪礼·士丧礼》的行礼者、角色分工和仪程进行分析 | 用于确认礼仪有过程和亲疏角色；研究对象是经典礼制，不是现代中国居民普遍行为调查 |
| [湖南省政府《土家族殡葬习俗》](https://www.hunan.gov.cn/hnszf/jxxx/hxwh/gms/201711/t20171111_4685324.html) | 介绍入殓、送葬、丧鼓与亲邻参与，包含地方民族特有仪式 | 作为差异证据：丧礼的气氛和形式并不一致；本作没有把土家族跳丧等地方做法混入所有角色的统一丧礼 |

父母离世是对人物生活有持续影响的转折，而不只是年表中的一个姓名。0.2.0 采用具名讣告、结束闭关、选择返乡或委托、按月治丧、素服、安葬、守丧、周年与期满。贫困可以记欠账，返乡仍由玩家作出回应；不同境况有简葬或委托方式。

24/6 个月、1 个月治丧、铜钱费用、70% 谋生收入与50%修炼积累是游戏的时间压缩和取舍，不对应全国统一的“三年之丧”、固定仪程天数或现实心理恢复时间。不会据此声称所有中国家庭必须采用同一礼制，也不会把不返乡写成统一的道德惩罚。

本作所有王朝、地点、人物、仙缘与数值都属于架空游戏。对丧礼使用事实参考，对修行使用公开类型机制与原创参数；两者的证据范围分别保留。
