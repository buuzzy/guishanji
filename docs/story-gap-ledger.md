## GAP-UI-001 · 凡人线结识的人，没有在小程序端落屏

| 项 | 内容 |
| --- | --- |
| 状态 | **未修**（登记于 2026-11-08） |
| 影响面 | 「与修仙无缘」那条线（12 条背景故事里有 4 条指向它） |
| 发现方式 | 清理网页端时对照「浏览器门禁 → Node 门禁」断言表（`docs/browser-gate-coverage.md` §1.4） |

**网页端（已删）**
- `apps/preview/life-panels.js` 的 `personRows()` 会把 `mundanePeople(s)`
  逐个人名画出来（药铺师傅、同住的伙计、雇主…）。
- 浏览器门禁 `verify-mundane-browser.mjs` 有一条断言：
  「凡人线的人要逐个上屏」。

**小程序端（当前）**
- `miniprogram/subpkg/xianxia/bridge/view-model.js` 的 `people()` 只列
  **家人 / 后代 / 旧相识 / 同行者**四类 —— **没有凡人线的人**。
- 实测（凡人线到 `m11_start`）：规则层名册里有「药铺师傅/扑哧君」「同住的伙计/美杜莎」，
  小程序端人物面板里一个都没有。

**钱粮那部分还在**
- 「灵石与家产」面板的说明写着「平日工钱用铜钱结算…」，
  家产（家中旧屋、外院通铺）也列着 ——
  ⇒ **只是钱粮的具体数字没有显示**，人物整个没显示。

**打算怎么修**
- 阶段 3.3（凡人线精简到 5 张）时一起做：
  ① `view-model.js` 的 `people()` 加一节「凡俗旧识」，数据问规则层的 `mundanePeople(s)`；
  ② 「灵石与家产」面板在凡人线时多一行「家中钱粮」，数字问 `mundane(s).money`；
  ③ 配套门禁：断言凡人线的人与钱粮**都**在面板上。
